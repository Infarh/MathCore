# Interpolation

Библиотека интерполяционных и аппроксимационных методов для численных вычислений.

## Интерфейс и базовые классы

### [`IInterpolator`](IInterpolator.cs)
Интерфейс одномерного интерполятора. Определяет индексатор `this[double x]`, метод `Value(double x)` для вычисления значения и `GetFunction()` для получения функции-предиката.

### [`Interpolator`](Interpolator.cs)
Абстрактный базовый класс, предоставляющий статические фабричные методы для создания линейных, Лагранжа и Ньютоновских интерполяторов, а также вспомогательный метод `Linear` для линейной интерполяции двух точек.

## Одномерная интерполяция

### [`Linear`](Linear.cs) — Линейная интерполяция
Находит значение функции на отрезке между двумя соседними узлами сетки по формуле:

$$y = y_1 + (x - x_1) \cdot \frac{y_2 - y_1}{x_2 - x_1}$$

Реализует бинарный поиск сегмента для эффективного вычисления. Статический метод `Interpolate` поддерживает вызов без создания экземпляра класса.

### [`Lagrange`](Lagrange.cs) — Полином Лагранжа
Строит глобальный интерполяционный полином:

$$L(x) = \sum_{i=0}^{n} y_i \cdot \ell_i(x), \quad \ell_i(x) = \prod_{\substack{j=0 \\ j \neq i}}^{n} \frac{x - x_j}{x_i - x_j}$$

где $\ell_i(x)$ — базисные полиномы Лагранжа. Идеален для небольшого числа узлов (до 10–15), поскольку имеет высокую степень $n$ и может страдать от колебаний Рунге.

### [`Newton`](Newton.cs) — Полином Ньютона
Интерполяционный полином через разделённые разности:

$$P(x) = f[x_0] + f[x_0,x_1](x-x_0) + f[x_0,x_1,x_2](x-x_0)(x-x_1) + \dots$$

Преимущество перед Лагранжем — возможность постепенного добавления узлов без пересчёта всего полинома. Статические методы `GetPolynomCoefficients` вычисляют коэффициенты разделённых разностей. Поддерживает равномерную сетку (параметры `x0`, `dx`).

### [`CubicSpline`](CubicSpline.cs) — Естественные кубические сплайны
Посегментная кубическая интерполяция, где на каждом отрезке $[x_i, x_{i+1}]$:

$$S_i(x) = a_i + b_i(x - x_i) + \frac{c_i}{2}(x - x_i)^2 + \frac{d_i}{6}(x - x_i)^3$$

Коэффициенты $c_i$ находятся методом прогонки для трёхдиагональной системы. Естественные граничные условия: $c_0 = c_n = 0$ (вторая производная равна нулю на концах). Обеспечивает $C^2$-гладкость. Бинарный поиск сегмента для $O(\log n)$ вычисления значения.

### [`BezierCurve`](BezierCurve.cs) — Кривые Безье
Параметрическая кривая, заданная контрольными точками $P_0, P_1, \dots, P_n$:

$$B(t) = \sum_{i=0}^{n} P_i \cdot B_{i,n}(t), \quad B_{i,n}(t) = \binom{n}{i} t^i (1-t)^{n-i}, \quad t \in [0, 1]$$

где $B_{i,n}(t)$ — базисные полиномы Бернштейна. Widely используются в компьютерной графике и CAD.

### [`BezierCurve2`](BezierCurve2.cs) — Кривые Безье (оптимизированная версия)
Внутренняя оптимизированная реализация с предвычисленной таблицей факториалов для ускоренного вычисления биномиальных коэффициентов.

### [`Spline2D`](Spline2D.cs) — Двумерная сплайн-интерполяция
Гладкая интерполяция двумерной кривой, заданной набором точек $(x_i, y_i)$. Использует параметризацию по кумулятивным расстояниям между точками и применяет сплайн-интерполяцию отдельно для $x(t)$ и $y(t)$. Обеспечивает равномерное распределение точек на выходе. Автор: Scott W Harden.

## Многомерная интерполяция

### [`InterpolatorNDLinear`](InterpolatorNDLinear.cs) — Многомерная линейная интерполяция
Линейная интерполяция в произвольном числе измерений. Поддерживает загрузку данных из CSV-файлов (включая ZIP и GZIP). Позволяет задавать селектор значений и обрабатывать некорректные строки.

### [`InterpolatorNDLagrange`](InterpolatorNDLagrange.cs) — Многомерная интерполяция Лагранжа
Обобщение метода Лагранжа на $n$-мерное пространство. Использует тензорное произведение базисных полиномов:

$$L(\mathbf{x}) = \sum_{i_1=0}^{n_1} \dots \sum_{i_d=0}^{n_d} y_{i_1,\dots,i_d} \cdot \prod_{k=1}^{d} \ell_{i_k}^{(k)}(x_k)$$

Поддерживает загрузку из CSV (ZIP/GZIP), нормализацию входных данных для численной устойчивости.

## Аппроксимация

### [`MNK`](MNK.cs) — Метод наименьших квадратов
Аппроксимация данных полиномом степени $m$:

$$P(x) = a_0 + a_1 x + a_2 x^2 + \dots + a_m x^m$$

Коэффициенты $a_0, \dots, a_m$ находятся решением системы нормальных уравмений, минимизирующей сумму квадратов невязок:

$$\sum_{i=1}^{N} \left(y_i - P(x_i)\right)^2 \to \min$$

### [`Biliniar`](Biliniar.cs) — Билинейная интерполяция
Интерполяция на двумерной сетке. Сначала линейная интерполяция по одной координате, затем по другой. Является частным случаем билинейной интерполяции на произвольных четырёх узлах.

### [`Mapping`](Mapping.cs) — Линейное отображение
Линейный интерполятор для отображения значений из одного диапазона в другой. Фактически — обёртка над `Linear` с явно заданными граничными точками $(X_1, Y_1)$ и $(X_2, Y_2)$.
